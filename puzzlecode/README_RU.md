# PuzzleCode 2.2 — Android

Нативное приложение Java + Android Activity/Canvas, без WebView/NDK. Пользователь загружает **уже перемешанный** PNG, вручную меняет любые два фрагмента, затем вставляет код восстановления. Исходная картинка не содержится в APK и не требуется для работы.

## Режимы

| Режим | Всего частей | Код |
| --- | --- | --- |
| 4×4 | 16 | \`PZ1.4.<base64url-16-байт>.<CRC32>\` |
| 100×100 | 10 000 | \`PZ2.100.<8 HEX-цифр seed>.<CRC32>\` |

После изменения режима нужно заново загрузить PNG. Ширина и высота PNG должны делиться на выбранное число частей вдоль стороны; для 100×100 рекомендуемый размер 400×400 или 800×800 пикселей. PNG не редактировать после генерации — код сверяет CRC32 по оригинальным байтам.

## Управление
- **Открыть PNG**: системный выбор документа, разрешения хранилища не нужны.
- **Одним пальцем**: перетащи одну плитку на другую для обмена, либо тапни по очереди две.
- **Двумя пальцами**: увеличение/уменьшение и перемещение изображения. Дополнительно доступны кнопки Увеличить, −, Целиком.
- **Сбросить перестановки**: восстановить первоначальное перемешанное положение из загруженного PNG.
- **Собрать по коду**: 4×4 анимируется по одному обмену, 100×100 — до 400 обменов за кадр. Все изменения, которые пользователь сделал до этого, учитываются.

Для 100×100 отображаются только видимые в текущем масштабе фрагменты (viewport culling), чтобы экран не перерисовывал каждый раз все 10 000 элементов при увеличении. Для планирования обменов используется алгоритм O(N).

### Тестовый PNG для 100×100
Имя: \`PuzzleCode_100x100_peremeshano.png\`, 400×400 px, код:
\`PZ2.100.13579BDF.728A6A58\`.

Создание собственной картинки:
\`python -m pip install Pillow\`
\`python tools/generate_puzzle.py ORIGINAL.png SHUFFLED.png 13579BDF\`
Утилита распечатает индивидуальный код сборки. Здесь seed описывает алгоритм перемешивания, CRC32 привязывает код к конкретным байтам PNG.

### Проект, сборка и проверка
- JDK 17, Gradle 8.11.1, Android SDK API 35, Android Gradle Plugin 8.9.2.
- \`./gradlew clean assembleDebug\` из каталога \`puzzlecode\`.
- \`app/build/outputs/apk/debug/app-debug.apk\` — итоговый APK.
- GitHub Actions: \`.github/workflows/puzzlecode-apk.yml\` — автоматическая сборка, проверка подписи и выдача артефактов с APK и полным ZIP исходников с Gradle Wrapper.
- Перед Android сборкой в Actions выполняется самостоятельный тест PuzzleCodecSmokeTest на Java 17: и 4×4, и 100×100, ручные обмены, проверка финальной перестановки.
- Package \`ru.sector9.puzzlecode\`, minSdk 26, targetSdk 35, compileSdk 35.
- Чистая Java без native .so, поэтому нет отдельных требований к ABI.
- Debug APK подписывается тестовым ключом GitHub runner. При обновлении ранее установленной версии с другим ключом может потребоваться удалить старую (при этом локальное состояние приложения будет потеряно; пользовательские PNG хранятся отдельно).

### Ограничения
- Максимальный файл ввода 25 МБ; декодирование до 2048 пикселей по большей стороне.
- Изначальные размеры картинки должны делиться на 100 для сетки 100×100. Из-за Android downsampling большие картинки могут не подойти; попробуй 400×400, 800×800 или 1600×1600.
- Полноценный запуск на физическом Android-устройстве следует подтвердить отдельно, даже если сборка и подпись успешны.
- При вылете: \`adb logcat -d -s AndroidRuntime:E\` и прислать строки \`FATAL EXCEPTION\` / \`Caused by:\`.
- При установке поверх другой подписи Android сообщает конфликт — в этом случае удалить старое приложение.

## Основные файлы
- \`app/src/main/java/ru/sector9/puzzlecode/MainActivity.java\` — интерфейс, загрузка PNG, масштабирование, касания, отрисовка.
- \`app/src/main/java/ru/sector9/puzzlecode/PuzzleCodec.java\` — форматы кодов, генератор перестановок, быстрое вычисление обменов.
- \`app/src/main/java/ru/sector9/puzzlecode/Config.java\` — редактируемые настройки.
- \`tools/generate_puzzle.py\` — создание перемешанного PNG и кода.
- \`tests/PuzzleCodecSmokeTest.java\` — проверки перестановок.
